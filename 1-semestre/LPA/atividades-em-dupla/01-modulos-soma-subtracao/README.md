# 01 — Módulos: Soma e Subtração

**Tipo:** em dupla com [Arthur (@ArthurBigdedd)](https://github.com/ArthurBigdedd)  
**Assuntos:** módulos (métodos `void`), menu com `switch`, `Scanner`

## Enunciado

Criar uma classe com 3 módulos: o principal pede dois números e mostra um menu (somar/subtrair); cada operação fica em um método separado que só imprime o resultado.

## Arquivos

| Arquivo | O que faz |
|---|---|
| `src/Main.java` | Menu de soma e subtração com métodos que imprimem o resultado |

## Como executar

```bash
cd src
javac -encoding UTF-8 *.java
java Main
```
