# 03 — Cadastro de Funcionário (leitura de dados)

**Tipo:** em dupla com [Arthur (@ArthurBigdedd)](https://github.com/ArthurBigdedd)  
**Assuntos:** entrada e saída de dados, tipos (`String`, `int`, `double`), `Scanner`

## Enunciado

Ler nome, peso, idade e salário desejado de um funcionário e mostrar os dados na tela.

> A versão original foi feita em Portugol (pseudocódigo) e convertida para Java aqui, com a mesma lógica.

## Arquivos

| Arquivo | O que faz |
|---|---|
| `src/CadastroFuncionario.java` | Lê os dados do funcionário e exibe um resumo |

## Como executar

```bash
cd src
javac -encoding UTF-8 *.java
java CadastroFuncionario
```
