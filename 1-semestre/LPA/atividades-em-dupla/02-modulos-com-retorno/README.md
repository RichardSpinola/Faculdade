# 02 — Módulos com Retorno

**Tipo:** em dupla com [Arthur (@ArthurBigdedd)](https://github.com/ArthurBigdedd)  
**Assuntos:** métodos com retorno (`int`), menu com `switch`, `Scanner`

## Enunciado

Mesma ideia da atividade 01 (soma/subtração via menu), mas agora `soma` e `subtracao` retornam o valor calculado e a impressão acontece no método principal.

## Arquivos

| Arquivo | O que faz |
|---|---|
| `src/MainComRetorno.java` | Menu de soma e subtração com métodos que retornam o resultado |

## Como executar

```bash
cd src
javac -encoding UTF-8 *.java
java MainComRetorno
```
