# 02 — Lista de Estruturas Condicionais

**Tipo:** individual  
**Assuntos:** `if`/`else`, operadores relacionais, `Scanner`

## Enunciado

Lista de exercícios (3 questões) sobre estruturas condicionais em Java.

## Arquivos

| Arquivo | O que faz |
|---|---|
| `src/L1_Q1.java` | Lê A, B e C e diz se A + B é menor ou maior que C |
| `src/L1_Q2.java` | Lê a idade e diz se a pessoa é maior ou menor de idade |
| `src/L1_Q3.java` | Questão 3 — ainda não resolvida |

## Como executar

```bash
cd src
javac -encoding UTF-8 *.java
java L1_Q1
```

Troque `L1_Q1` pela questão que quiser rodar.
