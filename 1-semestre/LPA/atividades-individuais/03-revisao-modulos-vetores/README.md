# 03 — Revisão de Módulos e Vetores

**Tipo:** individual  
**Assuntos:** métodos com e sem retorno, vetores (`int[]`, `String[]`), laços `for`, menu com `switch`

## Enunciado

Exercícios de revisão sobre módulos (funções) e vetores em Java.

## Arquivos

| Arquivo | O que faz |
|---|---|
| `src/ParImpar.java` | Diz se um número é par ou ímpar usando um método `boolean` |
| `src/Saudacao.java` | Lê nome e hora e responde bom dia, boa tarde ou boa noite |
| `src/CadastroAvaliacao.java` | Lê nome, peso e altura, calcula o IMC e emite um parecer |
| `src/MaiorInverso.java` | Preenche um vetor, mostra a posição do maior valor e a ordem inversa |
| `src/Gabarito.java` | Cadastra 4 alunos e notas, calcula a média, filtra aprovados e conta notas exatas |

## Como executar

```bash
cd src
javac -encoding UTF-8 *.java
java Gabarito
```

Troque `Gabarito` pelo exercício que quiser rodar.
