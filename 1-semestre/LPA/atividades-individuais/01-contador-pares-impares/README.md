# 01 — Contador de Pares e Ímpares

**Tipo:** individual  
**Assuntos:** laço `do-while`, operador `%`, contadores e acumuladores

## Enunciado

O usuário digita números até que sejam encontrados 10 números pares. A cada par, soma ao total e mostra o contador atual. No fim, exibe a soma dos pares e a média dos ímpares digitados (se houver algum).

## Arquivos

| Arquivo | O que faz |
|---|---|
| `src/ContadorParImpar.java` | Lê números até 10 pares e mostra soma dos pares e média dos ímpares |

## Como executar

```bash
cd src
javac -encoding UTF-8 *.java
java ContadorParImpar
```
